# Overview

This source summarizes the visual system for NexoERP ads and campaigns; product
components have their own library.[^fonte-07]

## Main content

- The palette combines Nexo Navy, Nexo Blue, Nexo Aqua, Cloud, Ink, Slate, and White,
  with functional colors for success, warning, error, and information.
- The main typography is Inter, with Arial as a safe fallback, and weights
  400, 600, and 700.
- Logo, shapes, buttons, photography, and illustration have their own uses and restrictions.
- Accessibility requires contrast, captions, alt text, and information that
  does not depend only on the image.
- The system defines feed, stories, reels, display, and LinkedIn document formats,
  as well as safe margins in stories and reels.

See [Design system for campaigns](/concepts/design-system-campanhas.md)
for the full values and rules.

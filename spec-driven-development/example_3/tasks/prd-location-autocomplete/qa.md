## Accessibility

The accessibility snapshot confirmed:

- `combobox` field named “City name”;
- coherent `aria-autocomplete="list"`, `aria-controls="location-suggestions"`, and `aria-expanded`;
- `aria-activedescendant="location-suggestions-option-0"` after ArrowDown;
- `listbox` named “Location suggestions” and options with `role="option"`;
- empty state in `status` and unavailability in `alert`;
- focus kept on the field during navigation, selection, and Escape.

No application JavaScript exceptions were observed. The browser logged the expected 503 during the unavailability case and a missing favicon 404, a note unrelated to the autocomplete flow.

## Found and fixed bugs

No product bugs were found.

During QA, an ambiguous assertion was fixed in the optional real-performance test: the heading search without exact match also made “Lima” match “Current weather”. The test now uses `exact: true` in `e2e/real-performance.spec.ts`.

## Conclusion

The 13 acceptance criteria were verified and met. The feature is approved for QA closure.

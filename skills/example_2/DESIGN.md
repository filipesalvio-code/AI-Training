# Design

<!-- impeccable:design-schema 1 -->

## Visual World

Creator hardware bench: a precise climate-reading instrument built into a mineral work surface. The interface uses a graphite chassis, bone controls, an amber measurement display and one safety-color action; weather conditions tune that action and signal color without changing the durable system.

## Surface: weather search

- **Mode:** Operate
- **Primary task:** Search for a city and read its current conditions immediately.
- **Composition:** Brand and a decisive heading open on a light work surface. Full-width search is the only primary action. The result is a single chassis: location and unit control at the top, illuminated temperature display on the left, metrics in a vertical measurement rail on the right.
- **Color strategy:** Restrained. Mineral neutrals and graphite carry the surface; one condition-aware signal color drives the action, indicators and icon accents.
- **Materials:** Bone control surface, gunmetal chassis, engraved inner frame and warm instrument display.
- **Type:** Archivo carries reading and control text; IBM Plex Mono is reserved for labels and measurements.
- **Motion:** A result settles into place once with a short vertical resolve. Reduced-motion users receive a still surface.
- **Responsive:** The header and search stack at narrow width. The instrument becomes a single vertical reading while retaining the display and the ordered metric rail.

## Accessibility

Text and interactive controls retain high contrast across every condition palette. Search feedback is announced in a polite live region; errors use an alert; focus remains clearly visible; decorative scene elements are hidden from assistive technology.
